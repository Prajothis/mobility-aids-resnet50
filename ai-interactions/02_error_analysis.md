# Interaction 01 – Model Fine-Tuning and Pipeline Setup

## 1. Context
**Task:** Investigate the prediction errors of the fined-tuned ResNet-18 binary classifier. 

The objective was to undertand where and under which curcumstances the model makes incorrect predcitions, rather than evaluatin its performance using accuracy alone. 
The analysis focused on fals positives, false negatives, category-specific performance, temporal patterns, and potential image-quality-related factors.

ChatGPT was used to support the analytical process, suggest investigation methods and implement the correspoing analyses. 

## 2. Important Prompts

**Prompt 1 – Brainstrom analytical direction**

> We have fine-tuned a ResNet-18 image classification model to determine whether an image contains mobility aids. We now treat the model as a black box and want to analyse its performance based on its inputs and outputs. Which metrics could we evaluate?

**Prompt 2 – Model evaluation**

> Write a Python script to evaluate the performance of our trained ResNet-18 model?

**Prompt 3 – Sequence analysis**

> My images come from video sequences. Build a script that visualizes the model's predictions and indicates whether each prediction is correct or incorrect. Use a suitable plot to analyse whether misclassified images occur close to each other within the same video sequence or are distributed across the sequence.

**Prompt 4 – More Detailed Sequence analysis**

> Suggest some useful visualization methods for video-sequenced images with classification results.

**Prompt 5 – Interactive Sequence analysis**

> Implement a temporal prediction path visualization for our dataset. Ensure that individual data points are clickable and that selecting a point displays the corresponding image alongside the previous and next frames, allowing me to compare visual differences between consecutive images.

**Prompt 6 – classification error rates per Categorie**

> The following annotation files also contain information about the objects visible in each image. Can you create a script that analyses the classification error rates separately for each object type? This will allow us to identify whether the model struggles more with specific objects.

**Prompt 7 - Resolution and Sharpness**
> Write a function that checks the sharpness, brightness and contrast

## 3. AI Contributions

- **Contribution 1:** ChatGPT recommended evaluating the model using accuracy, precision, recall and F1-score, as well as ROC-AUC and PR-AUC. It also suggested using a confusion matrix, false-positive and false-negative rates, and a classification report to better understand the model's performance.
- **Contribution 2:** A complete script was provided for model inference and performance evaluation. It calculates metrics such as F1-score, accuracy, precision, and recall, and generates ROC and Precision-Recall curves as well as a confusion matrix. 
- **Contribution 3:** A script was returned to identify the video sequences, along with a function that visualizes a selected sequence and plots all its frames, indicating whether each frame was classified correctly or incorrectly.
- **Contribution 4:** Suggested several visualization methods, including temporal carpets, run-length distributions, state transition matrix heatmaps, and temporal prediction paths.
- **Contribution 5:** After several specific follow-up prompts to refine the implementation, I ended up with a well-designed interactive Plotly visualization that provided all the desired functionality and allowed me to analyse exactly where classification errors occurred. The implementation was essentially fully generated by AI.
- **Contribution 6:** Received a script that generated a table for all object categories, showing the number of images containing each category, false negatives, false positives, recall, and false negative rate.

- **Contribution 7:** Received a function that takes an image_path, loads the corresponding image, and calculates its sharpness, brightness, and contrast values.

## 4. Implementation and Decisions

The suggested analyses were implemented in the 02_phase1_error_analysis notebook.

The main investigations included:

- Confusion matrix and classification metrics.
- Separate examination of false positives and false negatives.
- Analysis of annotation categories in incorrectly classified images.
- Category-specific recall and false-negative rates.
- Temporal analysis of prediction changes between consecutive frames.
- Comparison of image-quality characteristics between correct and incorrect predictions.

AI was initially used for brainstorming and exploring ideas based on the results of the first scripts. From there, I developed further ideas and mainly used AI to complete, refine, and generate the corresponding code.

## 5. Critical Evaluation

**What worked well?**

- It suggested several different ways to investigate possible causes of prediction errors.
- The interactive temporal analysis chart worked surprisingly well, and I think it turned out really cool.
- In general, generating code for specific ideas works extremely well. When the AI has sufficient context about the dataset, the generated functions work without any problems.

**What needed correction or refinement?**

- Generated code needed to be adapted to the existing notebook and dataset structure.
- Some analyses required additional checks to ensure that the correct images and annotations were matched.
- Temporal sequence groups were based on timestamp gaps and therefore needed to be treated as provisional.
- Image-quality measurements required careful interpretation because they do not necessarily explain why a prediction was incorrect.

**What were the limitations of AI assistance?**

- Some patterns needed to be checked by visually inspecting the corresponding images.
- ChatGPT repeatedly suggested the same analysis and visualization methods, even when using different prompts. It was therefore not always easy to find approaches that were truly specific to this dataset. Coming up with my own ideas was more helpful in discovering interesting and relevant analyses.

## 6. Lessons Learned

This project showed me that AI assistance is most useful when it supports a clear analytical idea rather than determining the entire direction of the analysis. Having my own questions and ideas was important for exploring aspects of the model that were particularly relevant to our dataset.

I also learned that generating code and interpreting results are two different things. Even when the code works correctly, the results still need to be checked and understood in the context of the dataset. Visual inspection and critical evaluation were therefore essential parts of the process.

Finally, I learned that interesting insights do not necessarily come from more complex analyses or visualizations. Sometimes, relatively simple approaches, such as comparing consecutive frames or examining specific error categories, can reveal useful patterns that standard performance metrics do not show.
